# faxuezhuan V2.0

这次把 faxuezhuan 升到 V2.0。原来只能转中文，现在西文也能转；中文这边补了报纸、译者、版次、无出版地、带卷期和“年份后多一个逗号”的期刊，以及无出版地的学位论文。

用法没变：打开 index.html，一行一条，点“转换”。西文期刊可以在格式一、格式二之间切；四人以上作者默认全列，不想全列就取消勾选，改用 et al.。标题斜体靠“一键复制”带过去，旁边还有“复制纯文本”。

报纸这块单独说一句：有作者的按“作者：《标题》，载《报纸》年月日，第X版”出；没作者就把题名放前面；多作者用顿号；版次可以省。顺手修了西文专著年份被当成页码的 bug，2027 不会再变成 p.2027。

几个边界先说清楚：GB 记录里没有年份、页码的，程序不编，只在下面提示；DOI 会识别后剥掉，不往输出里放；格式一只保留卷、刊名和首页，要起止页码就选格式二。报纸日期统一成“2025年10月1日”，版次 (002) 写成“第2版”。

页面没重做，还是原来的紫按钮和渐变，styles.css 基本没动；页脚换成了 getloli 计数器。代码还是 index.html、main.js、styles.css 三个文件，没有依赖，丢到 GitHub Pages 就能用。

原来的中文条目照旧能用，这次只是把支持的写法补全了。中文帮助按原来的编号加例子重写了，西文帮助另起一段。遇到转不出来的，先看提示，再把原条目发我。
